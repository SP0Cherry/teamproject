# 运维规范合规审计

审计范围：OPS-01 至 OPS-11
审计日期：2026-11-07

## 审计结果

| 规范项 | 判定 | 证据 |
| :--- | :--- | :--- |
| OPS-01 可复现构建 | 部分符合 | `requirements.txt` 锁定依赖；Dockerfile 存在；需核查基础镜像版本固定 |
| OPS-02 环境与配置 | 符合 | `.env` 注入配置；开发/测试/生产使用同一镜像 |
| OPS-03 健康检查 | 部分符合 | `health.py` 有 `/healthz` 端点；db 有 healthcheck；api/worker 无就绪检查 |
| OPS-04 结构化日志 | 符合 | `logging.py` 使用 structlog JSON 格式；含 request_id |
| OPS-05 指标与告警 | 不符合 | 无 Prometheus 指标与告警配置 |
| OPS-06 发布与回滚 | 部分符合 | docker compose 部署；无正式回滚脚本与发布记录 |
| OPS-07 数据变更顺序 | 符合 | alembic 迁移版本化；先迁移后启动 |
| OPS-08 备份与恢复 | 不符合 | 无备份策略与恢复演练记录 |
| OPS-09 性能与容量 | 不符合 | 无性能预算与慢操作监控 |
| OPS-10 限流与配额 | 不符合 | 无限流配置 |
| OPS-11 发布留痕 | 不符合 | 无 `docs/releases/` 发布记录 |

## 缺口清单

1. **OPS-05/09/10**：缺少指标、监控、限流 —— 后续变更
