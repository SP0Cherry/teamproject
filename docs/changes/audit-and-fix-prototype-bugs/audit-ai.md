# AI 规范合规审计

审计范围：AI-01 至 AI-10
审计日期：2026-11-07

## 审计结果

| 规范项 | 判定 | 证据 |
| :--- | :--- | :--- |
| AI-01 调用边界 | 符合 | 模型用于通知抽取、待办解析、问答、拆解建议；时间换算与状态流转用确定性规则 |
| AI-02 工具落点 | 符合 | 模型不直连数据库；通过 service 层调用 |
| AI-03 提示词即代码 | 部分符合 | `TODO_PROMPT`、`NOTIFICATION_PROMPT` 在代码中；无版本号与评测记录 |
| AI-04 模型与参数锁定 | 部分符合 | 模型参数由环境变量注入；temperature=0.2 硬编码；无集中配置清单 |
| AI-05 超时、重试与降级 | 不符合 | LLM 调用失败直接抛 ParseError，无降级；timeout=30s 硬编码 |
| AI-06 输出校验 | 部分符合 | `validate_output` 校验顶层 schema；不逐项校验 items；畸形结果直接报错 |
| AI-07 不编造依据 | 部分符合 | 需核查问答无命中时的拒答提示 |
| AI-08 外部内容的装配方式 | 符合 | 系统提示声明不执行资料内指令 |
| AI-09 评测集与回归 | 不符合 | 无评测集与回归报告 |
| AI-10 用量与成本观测 | 不符合 | 无用量记录与成本统计 |

## 缺口清单

1. **AI-05**：LLM 失败无降级（本次修复：回退规则解析）
2. **AI-06**：输出校验不逐项（本次修复：扩展 validate_output）
3. **AI-03/04**：提示词无版本号、参数无集中清单 —— 后续变更
4. **AI-09/10**：无评测集与用量统计 —— 后续变更
