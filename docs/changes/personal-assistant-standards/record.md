# 个人日常助手规范调整

## 变更说明

- 首期验收以个人账号的注册登录、通知确认、待办、资料管理、问答、日报与提醒为主。小组创建、加入、资料共享与通知发布列入首期。成员按组独立选择是否将通知同步到自己的待办。同步默认关闭，开启后同步新发布的通知，关闭时保留已同步待办。桌宠、动态壁纸和日常事件记录留待后续迭代。关联 PROD-01/02/11/13、TEST-01、OPS-06、REV-01。
- 资料轻编辑覆盖标题和可编辑文本，原附件独立保存。影响检索的修改使旧索引与对应答案缓存失效。新版本就绪后才进入问答。关联 PROD-09/12、BE-13/14、SEC-04/11/18、AI-07、DATA-08、TEST-02。
- 日报基础清单使用已确认待办等业务数据，AI 仅补充建议。加入当前有权访问的组内新增资料。关联 PROD-13、AI-01、TEST-02。
- 单实例发布可使用维护窗口，继续要求恢复验证。纯规范文档变更按实际结构、内容和链接检查留证。关联 OPS-06、TEST-12、REV-01/05/07。
