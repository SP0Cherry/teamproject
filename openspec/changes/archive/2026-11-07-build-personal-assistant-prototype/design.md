## Context

仓库已有项目总纲、八类规范及 OpenSpec 脚手架。当前没有应用源码、数据库迁移或业务门禁。使用 README 的 Vue 3、FastAPI、JWT 与 Docker Compose 方向搭建首期原型。产品动机见 [提案](proposal.md)，行为见各能力规格。

## Goals / Non-Goals

**Goals**

- 提供可在本地启动、可用不同账号端到端操作的中文工作台。
- 同时提供真实模型接入和明确标记的本地演示模式。测试可固定时钟、OCR 和模型输出。
- 让小组发布、个人待办、权限与检索版本各有明确的权威记录和可复验的失败路径。

**Non-Goals**

- 桌宠、动态壁纸、事件日记、任意 URL 拉取、原附件在线改写和原生客户端留待后续。
- 原型采用单机部署。多实例高可用与公网生产发布单独验收。

## Decisions

### 1. 单机应用边界

使用 Vue 3、TypeScript 与同源 Web 入口，FastAPI 接口层调用业务服务，再通过仓储或适配层访问 PostgreSQL、私有文件目录和外部模型。使用 PostgreSQL 与 pgvector 保存业务和检索数据，由 Compose 启动 Web、API、后台 worker 和数据库。原型共用数据库部署，独立向量服务可在容量证明需要时引入。API 采用 `/api/v1`，普通响应复用业务码、HTTP 状态和请求标识。后台受理返回 202 及状态入口，文档下载走单独响应契约。列表先授权再过滤和计数，时间排序追加唯一键并声明空值位置。

按模块划分账号、通知、资料、小组、待办、问答和日报。身份与权限判定集中在服务端。采用账号密码及 Argon2id，访问 JWT 仅驻留内存，刷新令牌使用 HttpOnly、Secure、SameSite Cookie 并轮换，服务端会话可立即撤销。Cookie 写请求校验 Origin，生产要求 HTTPS。评估过服务端会话 Cookie 方案，首期沿用 README 的 JWT 方向并用服务端会话保留退出语义。关联 [后端规范](../../../.agents/skills/teamproject-backend/references/standards.md) BE-01 至 BE-05、BE-09 至 BE-12 及 [安全规范](../../../.agents/skills/teamproject-security/references/standards.md) SEC-01 至 SEC-08。

### 2. 文件处理、索引和任务一致性

原附件进入服务端私有卷，经业务事务登记文件和待处理事件。解析 worker 在低权限、有限资源的环境中提取文本与来源位置。截图走 OCR，PDF 优先提取文本层并对需 OCR 的页数和渲染资源设限，DOCX 解包设限并禁用主动内容。组内上传须确认范围。个人资料和组资料共用文件处理流程。轻编辑保存新版本，旧版本立即排除检索及答案缓存。长内容按段落或语义边界切片，保留来源及索引版本，短内容同样可参与授权检索。删除先使访问失效，再清理副本。退组仅收回相应成员的访问并失效其缓存。

数据库内使用 Outbox 和可重领任务。发布、索引更新与清理登记在事务内写入，模型、OCR 和文件 I/O 在事务外执行。后台记录状态、超时、有限重试和请求关联。外部消息代理留作容量扩展。同步请求和异步投递都支持业务去重。关联 [后端规范](../../../.agents/skills/teamproject-backend/references/standards.md) BE-06 至 BE-08、BE-13 至 BE-16、[安全规范](../../../.agents/skills/teamproject-security/references/standards.md) SEC-03、SEC-09 至 SEC-15、SEC-18 及 [数据规范](../../../.agents/skills/teamproject-data/references/standards.md) DATA-01 至 DATA-09。

### 3. 组通知、时间与提醒

组创建者初始为管理员，首期通过邀请加入，成员可退出，管理员可管理邀请和成员。组通知草稿经有权成员确认后发布为版本化组记录。同步偏好属于用户与小组的成员关系，记录持续开启的版本或生效点。发布时确定资格，后台写入前在事务内以锁或版本条件复核持续开启、当前成员关系和通知有效性。以组通知任务标识和用户做唯一键。组通知修订只更新当前有权成员已同步待办的共享字段，退组后的待办保持个人快照。组通知列表始终按成员授权读取，日报任务来自个人待办。

精确时刻存 UTC，仅日期独立保存。列表、月历、问答和日报共用时间解释。提醒由后台使用时区和时间版本计算，投递前复核状态和版本，改期作废旧节点。考虑过将组待办作为实时共享视图，首期采用成员独立待办以保存个人完成状态、备注和提醒。关联 [产品规范](../../../.agents/skills/teamproject-product/references/standards.md) PROD-08、PROD-10 至 PROD-13。

### 4. 模型接入和安全降级

用服务端适配器配置实际文本模型和嵌入模型，集中记录模型标识、模板版本、参数、时限、用量与限额。AI 可抽取、解读和建议，身份、时间换算、状态流转与同步交给业务代码。抽取和拆解输出经过结构校验，并进入显式确认流程。问答优先查询已确认任务事实。资料检索在检索前限制范围，组装上下文前再检查授权和当前版本，返回前再次校验引用。提示词标记不可信文件内容，工具只调用受控业务方法。日报先加载规则清单，建议单独刷新及降级。演示模式使用合成样本与替身并显示演示标记，真实能力单独验收。评估过首期完全本地运行模型，保留适配层以便后续替换，原型无需自带模型权重。关联 [AI 规范](../../../.agents/skills/teamproject-ai/references/standards.md) AI-01 至 AI-10。

### 5. 界面与交互

采用浅色工作台。暖灰背景、白色内容面、深灰文字与靛蓝主操作，语义颜色配文字或图标。间距采用 4/8/12/16/24/32，辅助、正文、小标题、标题使用 12/14/16/20 或 24px。统一按钮、输入、上传区、标签、来源和弹窗；桌面采用固定导航与内容区，平板使用紧凑导航，移动端改为单栏。核心页面用同一组件基线，减少装饰层和重复卡片。

| 页面 | 路由 | 主要结构 |
| --- | --- | --- |
| 登录与注册 | `/login`、`/register` | 居中表单，明确字段错误和登录回跳 |
| 首页 | `/` | 日期和通知导入入口，主栏为今日任务与截止事项，次栏为组内新增资料与 AI 建议 |
| 通知导入与确认 | `/notifications/new`、`/notifications/:id/review` | 导入可粘贴或选文件，确认页左侧原文、右侧候选编辑，窄屏上下排列 |
| 待办 | `/tasks`、`/tasks/:id` | 列表与月历切换，时间分组、来源标签、详情与拆解 |
| 资料 | `/library`、`/library/:id` | 范围筛选、处理状态、原附件预览和轻编辑 |
| 小组 | `/groups`、`/groups/:id` | 创建与加入入口，详情分资料、通知和成员区，同步开关旁注明作用范围 |
| 问答与提醒 | `/assistant`、`/reminders` | 先显示问答范围和可展开的引用，提醒页显示触发时间与待办入口 |

所有数据页定义加载、空、失败与恢复操作。保持键盘焦点、弹窗回焦、标签和对比度。以真实长标题、无数据、OCR 失败和组同步关闭的合成数据做 375、768、1024、1440px 走查。关联 [产品规范](../../../.agents/skills/teamproject-product/references/standards.md) PROD-01 至 PROD-07。

## Risks / Trade-offs

- OCR 和模型输出存在不确定性 → 保留来源、允许修改及重试。以实际样本评估多事项、相对日期、模糊截图和注入。
- 异步任务可能与改期、编辑、撤权、关闭同步并发 → 事务内条件写、版本号和业务唯一键，重试时重新授权。
- 原型依赖和页面较多 → 每批形成可独立验证的交付单元，按 REV-02 控制每批人工维护文件数，确需超限时按 REV-06 登记。跨批使用同一模型替身和演示数据。
- 单机容量有限 → 明确解析并发、上传限制、模型预算、队列积压和备份恢复目标，以代表性数据记录实测值。

## Migration Plan

1. 创建开发和隔离测试环境。先运行初始化迁移，再启动 API、worker 和 Web。记录镜像、迁移、配置与模型版本。
2. 发布前验证注册、上传确认、资料索引、两组两成员同步、问答与日报。演练数据库和私有卷备份恢复，复核删除和撤权记录。
3. 应用回退使用上一版本镜像并检查待处理事件兼容性。首次部署失败时停止流量并保留数据用于诊断，恢复按迁移记录与备份方案执行。关联 [运维规范](../../../.agents/skills/teamproject-operations/references/standards.md) OPS-01 至 OPS-11 及 [评审规范](../../../.agents/skills/teamproject-review/references/standards.md) REV-02、REV-05 至 REV-07。
