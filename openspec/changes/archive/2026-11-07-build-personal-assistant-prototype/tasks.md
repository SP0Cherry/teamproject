## 1. 应用骨架与验证入口

- [x] 1.1 建立 Vue 3、FastAPI、PostgreSQL/pgvector 和 Compose 骨架，锁定依赖并提供无凭证的样例配置。用 `docker compose config --quiet`、初始化迁移及存活/就绪探针验证干净环境启动。
- [x] 1.2 实现统一 API 响应、请求标识、错误码和后台任务查询契约。通过契约测试核对非法参数、无权对象、依赖错误和 202 后任务失败的状态及业务码。
- [x] 1.3 建立独立测试数据库、私有文件目录、合成样本、可控时钟和外部依赖替身。运行空骨架的自动化入口，确认失败退出非零且不会读写开发库或调用外部服务。
- [x] 1.4 建立版本迁移和数据字典，登记归属、日期精度、索引、留存及敏感等级。用测试库执行初始化、重复执行及恢复检查，将结果登记到验收记录。

## 2. 账号与工作台

- [x] 2.1 实现注册、登录、轮换刷新、退出和逐资源授权。验证重复注册、错误凭据、重放已撤销令牌、异常 Origin、匿名深链接和跨账号请求。
- [x] 2.2 实现注册、登录和响应式工作台导航，统一色彩、字阶、间距、焦点、表单反馈与状态标签。浏览器走通登录回跳和未知路由，在 375px 与 1440px 检查导航和主要操作。
- [x] 2.3 实现个人与组资源的统一访问规则。为小组、文件、任务、会话及后台状态分别增加越权测试，核对内容、总数、预览及动作均按当前用户授权。

## 3. 通知导入与个人待办

- [x] 3.1 实现私有附件入库、限额校验、OCR/文档提取及后台处理状态。用文本、PNG/JPG、PDF、DOCX 及损坏、伪装、超限和空 OCR 样本核对成功和失败终态。
- [x] 3.2 实现服务端模型适配与通知抽取模板，校验输出结构、时间与来源。用合成样本检查多事项、无日期、相对日期、逆序时间、超时和注入；演示模式在界面显示标记。
- [x] 3.3 实现并排原文与候选的确认页、窄屏上下布局、候选增删与编辑，以及个人确认的事务和幂等。以两个会话和一条非法候选验证无半批写入，重试和并发确认最多产生一批。
- [x] 3.4 实现待办详情、时间列表与月历、完成和恢复。用相同截止时间、仅日期、无时间、跨时区和过期版本覆盖排序、日期边界与冲突提示。

## 4. 小组与资料

- [x] 4.1 实现小组创建、邀请加入、退出、成员管理和组详情。用创建者、普通成员和组外用户验证可进入的操作、邀请有效性及退出后权限立即回收。
- [x] 4.2 实现个人和组资料的上传、范围确认、原件与提取内容预览、标题和正文轻编辑及删除。验证成员可上传、越权编辑被拒绝、并发编辑保留新版本及原附件不变。
- [x] 4.3 实现组通知确认发布、列表、修订和撤回，复用通知确认流程。验证未确认不能发布、组外访问被拒绝、修订保留个人字段、撤回停止提醒。
- [x] 4.4 实现小组详情的个人同步开关与后台事务投递。以两组两成员和组外账号验证默认关闭、按组按人隔离、只能自改、新通知入待办、关闭保留已生成项、退组以及关闭再开启后的旧投递不补写，重复投递无重复记录。
- [x] 4.5 实现资料与通知的来源锚点、分段、向量化、版本化索引与失效清理。注入编辑、删除、撤权和重建乱序，检查旧版本立即排除，新版本就绪后命中，其他合法成员仍可访问组资料。

## 5. 问答、提醒与日报

- [x] 5.1 实现问答范围选择、已确认任务优先查询、授权检索与引用验证。用有命中、无依据、冲突、无权范围、撤权和注入样本校验答案、引用位置和权限。
- [x] 5.2 实现可编辑的任务拆解建议和人工确认。测试模型超时不改变待办，确认仅保存选中并校验过的子任务。
- [x] 5.3 实现站内提醒、用户设置、后台调度和去重。推进固定时钟验证默认节点、改期、完成、撤回、关闭、错过节点与并发投递。
- [x] 5.4 实现首页常驻清单、更新时间、刷新与分离的 AI 建议区。核对今日、未来七天和逾期分组，验证同步关闭时组内新增资料仍显示，模型失败时基础清单可用。
