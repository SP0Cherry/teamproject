## ADDED Requirements

### Requirement: 问答助手工具调用

系统 SHALL 允许问答助手在本地 RAG 检索之外，调用已登记的 MCP 工具（首个为 `duckduckgo_search`）补充回答。工具调用由模型按需决定，搜索结果作为上下文与本地检索片段一并提供给模型生成最终回答。回答须区分本地资料引用与外部搜索来源：本地引用使用 `[doc:附件ID:片段序号]` 格式，外部来源标注搜索结果标题与 URL。搜索工具因网络故障或限流不可用时，问答助手降级为仅基于本地资料回答，行为与变更前一致。

#### Scenario: 模型决定调用搜索

- **WHEN** 用户问题无法由本地资料充分回答且 `duckduckgo_search` 可用
- **THEN** 模型请求调用搜索工具，结果纳入上下文后生成回答，外部来源标注标题与 URL

#### Scenario: 本地资料足以回答

- **WHEN** 用户问题可由本地检索片段充分回答
- **THEN** 模型不调用搜索工具，直接基于本地资料回答，引用格式不变

#### Scenario: 搜索工具不可用

- **WHEN** DuckDuckGo 网络不可达、超时或被限流导致搜索工具调用失败
- **THEN** 问答助手降级为仅基于本地资料回答，不伪造外部来源，不报错

#### Scenario: 回答区分来源

- **WHEN** 回答同时引用本地资料和搜索结果
- **THEN** 本地引用保持 `[doc:附件ID:片段序号]` 格式，外部搜索结果标注标题与可点击 URL，不混用引用格式
