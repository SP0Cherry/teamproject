# 数据规范

以下规范适用于业务数据库、向量索引、对象存储、缓存及其备份，与既有权限、迁移和删除规则保持一致。个人资源独立归属账号，启用小组时才引入组归属与成员授权关系。

| 规范项 | 本项目的数据要求 | 检查与验收方式 |
| :--- | :--- | :--- |
| DATA-01 命名与类型 | 表名使用小写复数、字段名使用小写单数，统一 snake_case；关联标识使用对应单数资源名加 _id，时间戳使用 _at、仅日期使用 _date。精确时刻统一以 UTC 存储，保留展示所需时区；仅日期使用独立日期类型，不换算成 UTC 时刻，未知时间为 null。状态使用受约束的枚举或代码值，数据字典写明含义与合法流转；不把临期、逾期等派生标签作为可任意修改的完成状态。 | 比对数据字典与实现，检查命名、日期精度、空值及枚举；同一概念出现不同类型或风格即为缺陷。 |
| DATA-02 主键与外键 | 主键类型统一，外键沿用被引用主键类型；每条关联写明约束、索引及删除时的限制、置空或级联行为，不默认级联删除审计与已确认待办。个人资源带 owner_id，小组资源带 group_id，并约束归属范围合法；子资源通过自身字段或明确关联一次查询即可确定归属。冗余归属字段须防止与父资源不一致。切片、向量元数据保留文件标识、归属及内容/索引版本，不将其副本视为授权真相。 | 抽查文件、任务、会话及切片能否一次确定归属；插入跨组关联、不存在的父标识或不一致归属，应被约束或业务校验拒绝。 |
| DATA-03 审计字段 | 业务记录必备 created_at、updated_at、created_by，创建后时间与身份由服务端赋值；后台写入使用明确服务身份，不以空值代替。修改记录操作者或关联追加式变更日志，关键变更含对象、动作、版本、时间及必要差异；审计内容按敏感规则最小化保存。变更留痕只增不改，保留期到期的受控清理须另行记录。 | 抽查业务表及后台生成记录，字段齐备且不可由客户端伪造；修改通知后能定位操作者与版本，普通编辑不能覆盖历史。 |
| DATA-04 迁移纪律 | 已合入的迁移文件只增不改，新结构通过新迁移实现；迁移带唯一版本、前置条件、影响范围、回填及回滚说明。使用迁移记录与条件校验防止重复执行，不能用静默跳过掩盖结构不符；部分失败须可重试或按说明恢复。破坏性变更按既有兼容发布顺序执行；不可逆变更明确标记，提供备份恢复及补偿方案，不伪造可逆回滚。 | 审查历史迁移无改写；在测试库执行迁移、重复执行及中断恢复，验证可逆迁移回滚或不可逆迁移的恢复方案。 |
| DATA-05 数据字典 | 在 docs/ 中维护唯一数据字典，集中描述表与字段含义、类型、空值、默认值、枚举、归属、约束、索引及敏感等级；同时记录向量元数据和跨存储关联标识。接口与模块文档引用该字典，不另写冲突定义；结构或语义变更同步更新。 | 对照迁移、模型与变更说明，字段解释和约束应一致；没有登记的新字段或同名异义须修正。 |
| DATA-06 敏感数据分级 | 集中维护公开、内部、敏感、个人信息的分类与处理规则；个人信息可同时具有敏感等级，存在重叠时执行更严格规则。个人文件默认私有，组内共享不等于公开；密码摘要、令牌、模型凭证、联系方式及资料正文分别声明访问、存储和脱敏要求。复用既有统一脱敏实现，不在各模块自行定义；机密不返回，必要个人信息仅向有权用户展示。 | 抽查字典、日志、响应及导出，检查分级与访问范围；未经授权返回敏感原值或日志记录机密均判失败。 |
| DATA-07 留存与删除 | 在数据字典或其引用的唯一留存清单中，按原文件、提取文本、候选任务、正式待办、对话、日报、审计及备份写明保留期、起算点和清理方式，上线前不得留空。删除请求列出业务库、向量库、对象存储、缓存、临时文件及备份副本；先失效访问，再清理派生数据。备份按声明的保留期淘汰，不能即时清除的副本须隔离访问，恢复时先重放删除记录；保留待办快照须遵守既有规则并删除失效附件入口。 | 执行删除演练并逐项核对副本与完成状态；清理失败、备份未到期或恢复后均不得重新暴露已失效内容。 |
| DATA-08 跨存储一致性 | 业务库为归属、权限和版本的权威来源。上传先暂存文件，经业务事务登记文件与 Outbox，再异步提取、切片和建索引，完成后标记可检索；业务写入失败则清理孤立文件。资料原附件与可编辑文本分别管理。影响检索内容的编辑提交后，旧版本立即从检索与答案缓存中失效，新版本索引完成后才可用。过期任务不能覆盖当前索引状态。删除先在业务事务写失效标记与清理事件，再清理缓存、向量/切片和原文件，逐项记录结果。消费者按标识与版本幂等，写入前复核有效性，避免旧索引任务复活已删文件；定期对账并补偿遗漏。 | 在上传、编辑、建索引及删除各阶段注入失败，确认可重试、无重复或可见残留。并发编辑后让旧建索引任务晚于新任务完成，检索仍只使用当前版本；先删后到达的旧任务不得重建有效索引，孤立文件可被识别清理。 |
| DATA-09 测试数据 | 生产数据不直接进入开发、测试或模型评测环境，优先使用合成资料；确需样本时按明确权限在受控流程中脱敏、最小化后导出，并记录用途与清理时间。脱敏覆盖文件正文、截图、OCR 文本、对话、元数据及其关联标识，不能只替换账号字段；凭证和可恢复真实身份的映射不随样本导出。 | 抽查测试库、文件样本、评测集和仓库附件；发现未脱敏生产记录按安全事件处置，删除样本并追踪副本。 |
