# AI 模型调用规范执行技能

划分规则与模型职责，再检查检索授权、输出校验、引用和人工确认。

## 执行方式

1. 先读取 [完整规范与检查判据](references/standards.md)，按当前任务选择适用条目，不能只凭摘要实施变更。
2. 将适用编号（AI-01 起）关联本次场景、文件或 OpenSpec 任务，明确输入、预期结果与失败判据。其他领域按根目录总纲读取，不默认加载全部技能。
3. 实施或评审时重点检查：调用边界、工具、模板版本、超时、无依据拒答与评测。保留用户已确定的边界与授权。
4. 执行适用检查；暂无脚本时可人工完成并记录步骤，不能将未执行、依赖缺失或仅有计划写成通过。
5. 交付列出适用规则、改动位置、检查步骤或命令、实际结果和未完成项；按评审规范关联必要证据。

参考文件是详细规则的唯一维护位置，本入口只维护触发范围与流程。编号保持稳定，新增规则追加编号，删除编号不复用。更高优先级指令与用户明确要求优先，冲突需说明。
