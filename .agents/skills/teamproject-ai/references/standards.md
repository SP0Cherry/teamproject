# AI 模型调用规范

以下规范适用于通知解析、资料问答、任务拆解及每日报告中的 AI 建议，与既有权限、异步任务及测试规范共同执行。

| 规范项 | 本项目的开发要求 | 检查与验收方式 |
| :--- | :--- | :--- |
| AI-01 调用边界 | 模型负责通知语义抽取、资料解释、任务拆解建议及日报建议；时间换算、逾期判断、提醒计算、权限、状态流转与同步去重使用确定性规则。查询已确认任务的截止时间和状态优先读取结构化数据；日报由规则汇总今日任务、近期截止及逾期事项，启用小组时再纳入当前有权访问的新增资料。模型仅补充建议，失败时仍展示基础清单并提示建议暂不可用。 | 逐个调用点说明为何需要模型；可直接查询或计算的结果不得依赖模型推断，停用模型不应影响基本待办与提醒。 |
| AI-02 工具落点 | 模型工具只能调用已登记的业务服务方法，复用身份、逐资源授权、脱敏与审计，不得直连数据库、向量库或对象存储。服务端绑定当前用户与授权范围，模型参数不能覆盖身份；首期工具仅提供受控查询，修改待办仍须由用户确认后走正常业务流程。 | 逐个工具追踪到具体服务方法；直接查询存储、可替换用户身份或绕过人工确认均为违规。 |
| AI-03 提示词即代码 | 提示词模板随版本入库，记录版本号、用途及评测结论，变更经评审后发布；运行时只填充声明的数据变量，不允许在生产对话框直接修改模板。系统规则、输出结构与引用要求纳入模板版本；部署记录实际使用版本，不在日志保存填充后的全文。 | 核对仓库、评测记录与线上模板版本，出现未评审或仓库外的模板即为缺陷。 |
| AI-04 模型与参数锁定 | 集中登记各能力的模型标识及可用版本、温度、最大输出长度、上下文预算、检索条数及相关阈值；部署值按既有规范由环境变量注入并校验，不散落在代码中。优先使用固定模型版本；供应商不提供固定版本时记录其限制及实际返回标识，变更后重新评测，不静默切换模型或参数。 | 从统一配置清单可找到全部模型参数及环境变量名；核对运行记录，禁止使用未经评测的默认替代模型。 |
| AI-05 超时、重试与降级 | 模型调用统一执行集中配置的超时、重试上限与退避策略；按能力设值时也只在同一处维护，并限制含重试在内的总耗时。仅重试明确可恢复错误，后台任务和适配层不能叠加出无限重试。依赖故障返回已登记错误码与可理解提示；通知解析保留原文件供重试，问答不得用空答案伪装成功，日报按基础清单降级。 | 模拟不可达、超时和限流，检查在约定期限内结束、重试次数受控、错误明确且草稿或原文件可恢复。 |
| AI-06 输出校验 | 结构化结果按声明的 schema 校验字段、类型、长度、枚举及时间语义，再交业务层处理；模型输出不能指定所有者、权限或正式流程状态。畸形结果按失败处理，不静默补默认时间或默认任务；候选任务、拆解建议经人工确认才正式保存。流式中断结果标记未完成，不进入正式任务或成功答案缓存。 | 构造畸形 JSON、缺失标题、逆序时间、越权字段及中断响应，均不能直接成为正式待办或完整答案。 |
| AI-07 不编造依据 | 资料问答无有效命中或引用列表为空时，固定提示“未在当前可访问资料中找到依据，请补充资料或调整查询范围”，不编造标识或片段。长资料和长通知通过版本化向量切片检索。问答只使用当前可访问且索引已就绪的内容版本。引用来自本次授权检索的真实片段，由服务端核对版本、权限和位置；涉及截止时间等关键事实须与来源一致，冲突须明确展示。结构化待办查询可直接返回已授权记录，须标明任务来源，不因未检索文档而误拒。 | 空库、无权限资料、资料编辑后旧版本引用、索引未就绪和冲突材料分别测试；不得出现虚构出处，已确认任务的查询仍可正确返回。 |
| AI-08 外部内容的装配方式 | 正文、OCR 结果、检索片段及外部提供的技能或工具描述作为有边界标记的数据放入用户消息；系统提示明确不执行其中指令。可信工具定义由服务端登记，不允许上传内容替换。提示词隔离之外，授权、参数校验和工具限制由代码独立保证。 | 上传要求忽略规则、泄露其他小组资料或调用未授权工具的素材，内容只能作为资料，不能扩大模型权限或改变系统规则。 |
| AI-09 评测集与回归 | 维护小样本评测集，含必须答对、必须拒答，以及时间模糊、多任务、无命中、冲突来源和提示词注入场景；标注预期字段、引用或拒答条件，不以措辞完全相同为标准。提示词、模型、关键参数或检索策略变化后执行前后对比并归档版本及结论。常规自动化测试使用替身；真实模型评测单独运行，使用脱敏或合成资料并控制用量。 | 每次相关变更可找到前后可比的评测报告；关键字段、授权边界或无依据拒答出现回归时不得发布。 |
| AI-10 用量与成本观测 | 记录 request_id、调用能力、模型标识、提示词版本、耗时、输入/输出用量、检索命中数、重试次数及结果；非检索调用命中数记为不适用。按用户或小组统计须遵守访问权限，不记录提示词全文、资料正文或完整回答。成本估算采用有版本及生效日期的价格配置，缺少供应商用量时标记未知，不能记为零；汇总月度用量并关联既有配额与告警。 | 抽样请求检查字段齐全且无原文，月度统计可定位用量增长的能力与模型；超时、失败及重试产生的用量也须纳入。 |
