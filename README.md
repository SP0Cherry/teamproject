# teamproject
云端AI助手 
一． 主要功能 
日常学习或工作时，各种通知信息比较分散，部分通知
冗长不易阅读。本项目将利用AI统合整理所有通知等信息，
从而形成待办清单，并提供附加的AI问答，每日报告/建议，
临期提醒等功能。 
1. 注册/登录。 
2. 上传通知文件，可以文本粘贴，截图，或pdf，word等
常见格式。由AI解析，抽取任务标题，详情，起止时
间等，经人工确认（可以编辑补充）后加入待办清单。 
3. 也可以上传学习资料文件。长资料或通知文件需要切片
向量化。 
4. 支持创建/加入小组，组内成员上传的资料共享，每个
成员都可以上传文件。组内发布的通知会同步到各个成
员的待办清单 
5. 展示用户的待办，可以按事件的时间以条目显示，也可
以绘制日期表。显示该待办的来源（个人上传或某个组
发布），任务标题，详情，起止时间。若有大型任务可
以拆解或提前提醒。 
6. 支持AI问答，比如询问AI 某某事务截止日期是多少，
具体要做什么。或者也可针对资料询问。 
7. 常驻显示每日报告/建议，包括近期DDL，今日任务，组
内新增资料， 
二． 技术方案 
前端初步选择 Vue3，后端 python+fastapi，登录使用
JWT 实现，上传的文件中，小文件直接保存到数据库，长文
件采用切片向量化。AI 问答时对长文件使用 RAG。部署在
Docker Compose 中。用户登录后，若为当天第一次登录，则
调用ai生成今日报告。
