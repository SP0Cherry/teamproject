# teamproject

个人日常助手，帮助用户整理学习、工作和生活中的通知、待办与资料。

## 首期范围

1. 注册与登录。
2. 导入通知，支持粘贴文本、截图、PDF 和 DOCX。AI 提取任务标题、详情及起止时间，用户可对照原文修改和补充，确认后生成待办。
3. 上传个人资料，支持阅览原件、编辑标题和可编辑文本。资料进入个人知识库，长资料和长通知切片并向量化。影响检索的编辑提交后，按当前版本重建索引。
4. 按时间查看待办列表，展示来源、标题、详情与起止时间。日历可作为同一模块的视图。大任务可生成拆解建议，经确认后保存，也可设置提前提醒。
5. 就任务时间、具体要求或资料内容向 AI 提问。已确认任务的事实优先取自待办数据，资料答案附可访问的来源。
6. 首页常驻日报和建议，展示今日任务、近期截止事项与逾期任务。基础清单可独立生成，AI 补充建议。

## 可选扩展

- 小组支持创建与加入，成员均可上传和阅览组内共享资料。启用后，日报展示当前可访问的组内新增资料。
- 可单独启用组通知同步。发布前由有权成员确认，发布后同步到成员待办并保留小组来源，各成员独立管理完成状态。
- 桌宠、动态壁纸、日常事件记录等能力在后续迭代中按需设计。

## 初步技术方案

前端考虑 Vue 3，后端考虑 Python 和 FastAPI，登录考虑 JWT，部署考虑 Docker Compose。文件保存和检索索引分别设计，长内容使用向量检索辅助问答。

## 项目规范入口

- 常驻总纲：[AGENTS.md](AGENTS.md)。
- 八类规范与技能：[分类入口](AGENTS.md#分类入口)，正文只在各技能 references/standards.md 维护。
